# MINI-PROJECT
Amazon Sales Analysis

This project focuses on cleaning and preparing the Amazon Sales Dataset using Microsoft Excel Power Query.
The main objective is to improve data quality by handling missing values, correcting data types, cleaning text fields, and removing unnecessary columns before further analysis.

Dataset Source

* Platform: Kaggle
* Dataset: Amazon Sales Dataset⁠
* Rows Used: First 1,000 rows


* ⁠* Applied Trim and Clean to text columns.
* Removed unnecessary columns:

* Split the original Category column into three separate columns:
    * Category
    * Subcategory
    * Product Type

* Identified missing values in the dataset.
* Replaced two missing values in rating_count using median imputation.
* Replaced missing Product Type values with “Not Available”.
