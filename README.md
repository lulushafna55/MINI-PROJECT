# MINI-PROJECT
Superstore sales Data Analysis
Project Overview

This mini project focuses on analyzing Superstore sales data using Microsoft Excel and Power BI. The project aims to understand sales performance, profitability, customer behavior, and regional performance through interactive dashboards.

Project Objectives

Analyze overall sales and profit performance.
Identify top-performing product categories and sub-categories.
Understand customer and regional sales patterns.
Analyze monthly sales trends.
Create interactive dashboards for business analysis.
Tools Used

Microsoft Excel
Power Query
Microsoft Power BI
DAX
Dataset

The Superstore Sales dataset was obtained from Kaggle.

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

Data Cleaning

Data cleaning and preparation were performed using Microsoft Excel and Power Query.

Key activities included:

Checking and correcting data types.
Converting Order Date and Ship Date into date format.
Creating Unit Price.
Checking data quality and duplicate records.
Validating shipping days.
Preparing data for analysis.
